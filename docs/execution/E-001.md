## Release and rollback notes

- **릴리스 영향:** 플러그인 버전과 사용자 배포 산출물은 바뀌지 않는다. 이후 태그 릴리스는 같은 SHA의 성공한 Governance push run을 요구한다.
- **생성 산출물:** `main.js`를 재생성하지 않는다. Register만 문서 frontmatter에서 재생성한다.
- **롤백 단위:** 새 docs, validator, workflow, package script, AGENTS 변경을 한 묶음으로 되돌린다. release job 분리만 되돌릴 때도 기존 검증 gate는 유지한다.
- **데이터/설정 복구:** 런타임 데이터 변경이 없어 복구가 필요 없다.
