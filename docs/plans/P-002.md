# P-002 — Achmage Slides Ultra 1.1.0 통합 릴리스

## Outcome

- **목표 결과:** Open Slide Preview의 2D frame 구조를 유지하면서 기본 입력을 문서 읽기 순서로 통일하고, 상시 route 상태·계층 counter·명시적 section 이동·접근성을 제공한다. 동시에 Community Scorecard의 저위험 warning과 dependency risk를 줄이고 Node 24 기반 draft release를 만든다.
- **사용자 가치:** 처음 보는 사람도 `2-1 → 2-2 → 2-3 → 3-1`의 연속 흐름을 발견·완주할 수 있고, 숙련자는 별도 section 버튼으로 논리 단위를 건너뛸 수 있다. 기능·capability·자동 파싱의 안정성을 훼손하지 않으면서 릴리스 신뢰 신호도 개선한다.
- **완료 정의:** AC-201~AC-212가 E-002에서 정확히 한 번씩 PASS하고, canonical `1.1.0` artifact·버전 tuple·draft asset·검증 hash가 일치한다. R-004에서 탈락한 성능 후보는 제품 diff와 릴리스 claim에 포함하지 않는다.

## Requirements and non-goals

### 요구사항

- `Right`, `Down`, `PageDown`, `Space`, `N`과 stage 우측 클릭은 다음 frame, 역방향 입력은 정확한 이전 frame으로 이동한다.
- `Home`/`End`는 실제 deck 첫·마지막 frame, 별도 Previous/Next section 버튼은 인접 section의 frame 0으로 이동한다.
- 하단 bar는 route-aware Previous/Next, `Section x/y · Slide a/b`, section 이동, fullscreen/help의 계층을 유지하고 320~1920px에서 넘치지 않는다.
- dots는 native button, 설명 가능한 이름, 24px 이상 hit area, contrast-stable 표시, roving tabindex와 bounded/scrollable locator를 갖는다.
- current frame만 accessibility tree/tab order에 노출하고 iframe title, 짧은 live status, focus 복구, reduced-motion을 제공한다.
- global key handler는 authored control, dialog, modifier, `defaultPrevented`를 침범하지 않으며 focused control의 Space/Enter action을 중복 실행하지 않는다.
- Live Preview와 exported HTML에 같은 조작 grammar·help를 적용한다.
- dependency patch와 `esbuild@0.28.1`을 분리 검증하고 production/full audit 0, type-aware lint, Scorecard preflight를 제공한다.
- runtime-erased assertion/receiver cast는 byte-identical을, iterator `done` guard는 예상 diff와 cache parity를 각각 검증한다.
- 네트워크 이미지, export base64, clipboard write-only, local FileSystemAdapter capability를 숨기지 않고 README에 정확히 공개한다.
- GitHub Actions는 Node 24를 사용하고 tag workflow는 attestation을 유지한 draft만 만든다.

### 비범위

- 공개 TypeScript API, 설정 schema, 저장 상태, `SlideMapEntry`, parser, Pretext 측정·overflow 알고리즘의 의미 변경
- coach mark, floating overlay, `navigationHintSeen`, 새 render option·iframe message·전역 section 단축키
- first-party `eval`, Math 엔진, Highlight 언어, embedded asset 제거
- R-005 Remotion 코드·의존성·릴리스 노트
- R-004 C-001(selected-theme/adaptive-settle), Browser-platform build 또는 근거 없는 performance claim
- source가 유실된 `acceptance:native-1920-v5`의 복구·삭제·재사용
- mobile export 정식 지원, migration, tag/asset 덮어쓰기
