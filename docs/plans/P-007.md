# P-007 — Achmage Slides Ultra 1.2.0 One-click MP4 Export

## Outcome

- **목표 결과:** 1.1.4의 deterministic Markdown→physical SVG pipeline을 재사용해, Open Slide Preview와 command palette에서 1920×1080/30fps/silent H.264 MP4를 한 번의 modal로 생성하는 minor release `1.2.0`을 배포한다.
- **사용자 가치:** 이미 자동 보정된 slide deck을 AI token, cloud upload, 별도 FFmpeg/Remotion 설치 없이 Windows/macOS에서 일반적인 `.mp4`로 저장한다.
- **완료 정의:** owner Electron 37.3.1, latest official Windows Obsidian, latest official macOS arm64 Obsidian의 encode→mux→decode qualification이 먼저 통과하고, E-007에서 AC-701~AC-714를 각각 정확히 한 번 PASS로 종결한다. 어느 qualification 또는 Scorecard Satisfactory gate가 실패하면 제품 release를 중단한다.

## Requirements and non-goals

### 요구사항

- Branch `codex/release-1.2.0-mp4-export`는 GitHub default release branch `b28c160…` 제품 tree에서 시작한다. 개발 중 default branch를 `main`으로 바꾸지 않는다.
- Remotion package/source/runtime/telemetry는 0이다. exact `mediabunny@1.52.3`만 production dependency로 사용하고 MPL source notice를 tagged release에서 접근 가능하게 한다.
- 제품 구현 전 owner Windows Electron 37.3.1과 official Windows/macOS Obsidian에서 actual 2-second H.264 MP4 encode→decode를 통과한다. WebM/external FFmpeg/server/Remotion fallback은 없다.
- `VideoDeckArtifactV1`은 final audited physical SVG와 section/frame topology, shared CSS/font, normalized assets, immutable snapshot/hash를 가진다. Markdown을 재파싱하거나 React slide를 재구성하지 않는다.
- Video capture는 local/remote/font/background asset readiness와 normalized capture document의 final overflow `≤2px`를 보장한다. 누락 asset은 hard failure다. raw `deck.html`을 MP4 audit iframe에 넣기 전에 각 correction pass의 asset을 bounded/self-contained artifact로 normalize한다. decode 전에 format-aware dimension(GIF logical screen + descriptor bounds, AVIF 모든 `ispe` 합산 포함), nested data asset, non-base64 data URI allocation-free UTF-8 upper bound, compressed byte, cumulative pixel과 serialized-artifact budget을 검사하며 budget 초과·ambiguous header·ICO·nested data font·active nested SVG/`marquee`/`progress`·모든 nonempty legacy `background` attribute·escaped/comment-obfuscated CSS animation/resource/URL argument·quoted-string `image-set()`·`input[type=image]`·animated raster/APNG/AVIF sequence는 actionable failure다. nested SVG resource는 parsed XML DOM의 namespace/localName/full style text로 검사하고 CDATA/prefix 우회를 허용하지 않는다. fragment-only URL은 non-fetch SVG presentation/local href만 허용하며 image/background 등 fetch-capable context는 거절한다. post-decode 누적 상한은 실제 natural dimensions로 다시 검증한다.
- Timeline은 30fps, user hold `0.5~60.0s` step `0.1`, default `3.0s`, fixed transition `0.3s/9 frames`다. same-section은 vertical, section boundary는 horizontal, progress는 smoothstep으로 frame-index에서만 계산한다.
- Encoder는 H.264/AVC, target 8Mbps, keyframe 60 frames, `Mp4OutputFormat({fastStart:"reserve"})`, exact `maximumPacketCount`를 사용한다. partial은 최초 `wx+` handle을 닫거나 path로 다시 열지 않고 `StreamTarget` positional write와 같은 handle의 `CustomSource` validation에 사용한다. pop-out document의 realm 차이와 무관하도록 encoder output은 module-realm `OffscreenCanvas`를 사용하고, owner document에서 decode한 current/next bitmap만 유지한다.
- Command `Export current note as MP4`와 Preview `Export MP4`는 같은 single-job service/modal/progress/cancel을 사용한다. output은 note 옆 collision-safe `.slides.mp4`이며, note stem을 반복하지 않는 same-directory `.achmage-video-<uuid>.partial.mp4`의 최초 file identity를 encode·validate·commit 전후 확인한 뒤 no-overwrite hard-link와 partial unlink로 승격한다. hard-link 미지원 또는 identity mismatch는 비원자 rename/copy로 폴백하지 않고 실패한다. Node에 conditional inode unlink가 없어 cleanup의 `lstat→unlink`에는 로컬/provider 교체 micro-race가 남음을 공개하고, 테스트된 replacement interleaving에서 unknown path를 보존한다.
- 모든 resolved image는 outer SVG와 별도로 decode/readback하고, normalized asset capture를 공용 CSS 1회인 offscreen document에서 다시 probe해 final overflow ≤2px를 확인한다. embedded video/iframe/object와 SVG image 내부 nested external asset은 조용히 누락하지 않고 fail-closed한다.
- Cancel은 encode/verify의 각 await 뒤 재확인하고 Mediabunny input을 dispose하는 bounded 동작을 하되, 이미 시작된 한 번의 local fsync/read는 완료될 수 있다. 검증 완료 후 atomic hard-link publication이 시작되면 버튼을 잠그고 완료 결과를 보고한다. publication 뒤 private partial unlink가 한 번 실패하면 cleanup을 재시도하고, 최종 파일과 partial의 실제 경로를 숨기지 않는다.
- 일반 Preview/HTML export에서는 video artifact를 생성·보관하지 않는다. public API, settings schema/persistence, parser, Pretext, overflow packing, navigation grammar는 보존한다.
- `manifest.minAppVersion`과 `versions.json["1.2.0"]`은 `1.13.4`다. app version과 runtime codec capability는 별개로 검사한다.

### 비범위

- Audio, TTS, captions, background music, per-slide directives, embedded video sampling, element-level motion, timeline editor
- WebM, MOV, GIF, 4K, custom resolution/fps/codec/bitrate UI, external FFmpeg, cloud/server renderer, native sidecar
- Remotion dependency 또는 Remotion-powered marketing
- Mobile support, settings migration, `getSettingDefinitions()`, existing Clipboard/Dynamic Code Execution/Direct Filesystem capability 제거
- Raw MP4 byte-identical 보장; decoded frame determinism만 보장
