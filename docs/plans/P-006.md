# P-006 — Achmage Slides Ultra 1.1.4 Navigation Polish 릴리스

## Outcome

- **목표 결과:** 공개 1.1.3의 parser·Pretext·overflow·navigation grammar와 API/schema를 보존하면서 fullscreen 버튼 진입의 keyboard dead state와 stage 주황 focus perimeter를 수정하고, visible Home과 명시적 fullscreen action label을 추가한 patch `1.1.4`를 배포한다.
- **사용자 가치:** fullscreen을 켠 직후 추가 click 없이 방향키를 사용할 수 있고, 긴 deck 어디서나 하단 Home 한 번으로 첫 slide에 돌아가며, fullscreen button의 현재 action을 즉시 이해할 수 있다.
- **완료 정의:** E-006에서 AC-601~AC-608을 각각 정확히 한 번 PASS로 종결한다. Exact Dashboard preview가 1.1.3보다 악화되지 않은 경우에만 ready PR→merge→annotated tag→attested three-asset release를 진행하며 Community review 요청은 owner가 수동으로 수행한다.

## Requirements and non-goals

### 요구사항

- Branch `codex/release-1.1.4-navigation-polish`는 exact `origin/main` `3056c40199d6db8777fdd04323c1f21b6d49d652`에서 시작하고 GitHub default branch는 `main`을 유지한다.
- Fullscreen 성공 진입에서만 stage를 `preventScroll` focus하고 stage의 noninteractive default outline만 제거한다. 요청 실패와 종료 focus, button/dot focus-visible, interactive-target guard와 focused-control Space/Enter는 보존한다.
- Previous 앞에 native Home을 추가해 existing `firstInDeck()`만 호출하고 deck 시작에서 disabled로 표시한다. activation 뒤 stage focus로 sequential keyboard context를 복구한다.
- Fullscreen visible action은 wide `Fullscreen on/off`, narrow `FS on/off`; ARIA는 `Enter/Exit fullscreen`과 `aria-pressed`를 유지한다.
- Home/fullscreen utility는 fixed shell colors `#00B5AD`, `#061A19`, hover `#16C7BE`, active `#009B94`를 사용하고 disabled Home은 existing neutral state를 사용한다.
- Live Preview와 desktop exported HTML의 shared shell, help와 README를 동기화한다. 320/480/800/1920px에서 bottom row overflow가 없어야 한다.
- Version tuple은 package/lock/manifest `1.1.4`, `versions.json["1.1.4"] = "1.7.2"`로 맞추고 clean deterministic `main.js`, bilingual notes와 three release assets를 제공한다.

### 비범위

- 공개 TypeScript API, `AchmageSettings`, 저장 데이터, parser, `SlideMapEntry`, Pretext/overflow, frame topology, navigation transition algebra, section shortcut 변경
- Interactive-target ownership 완화, 새 전역 shortcut, coach mark, 설정/migration, dynamic slide-theme accent propagation
- `getSettingDefinitions()`, Direct Filesystem, Clipboard, Dynamic Code Execution, dependency graph, Scorecard scanner 우회
- Remotion/MP4, loading/preview 성능 최적화, release workflow/governance-core 리팩터링
- 기존 tag/release/asset overwrite 또는 Community `Request review` 자동 실행
