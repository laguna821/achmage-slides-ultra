# P-008 — 1.2.0 codec qualification gate reconciliation

## Outcome

- **목표 결과:** P-007과 R-005의 2026-08-05 owner 결정에 맞춰 real-Obsidian codec qualification의 종료 판정을 교정한다.
- **사용자 가치:** 정상적으로 생성·재생되는 MP4를 host별 손실 압축 반복 픽셀 차이만으로 차단하지 않되, 실제 codec 기능 실패는 계속 fail-closed한다.
- **완료 정의:** pre-encode compositor, one-shot 정책, H.264 encode→mux→parse→decode와 필수 metadata만 release blocker로 남고, REC-016 decoded-repeat 수치는 report에 보존되지만 exit status를 바꾸지 않는다. 제품 source와 `main.js`는 byte-identical이어야 한다.

## Requirements and non-goals

### 요구사항

- `scripts/video-codec-qualification.mjs`의 host verdict를 REC-017 core/REC-016 diagnostic으로 분리한다.
- Existing probe가 생성하는 두 encode run, exact pre-encode samples, metadata와 decoded diff 원본은 모두 보존한다.
- Capability/encode/mux/parse/decode, output/hash, cleanup, one-shot/no-retry와 metadata 실패는 계속 nonzero exit다.
- Report schema를 4로 올려 core result와 decoded-repeat diagnostic을 구분한다.

### 비범위

- `src/**`, `scripts/video-codec-probe.ts`, encoder config, dependency, version tuple, release assets와 public API 변경
- Codec/performance 재측정 확대, 새 threshold 또는 성공 run 선택
- Dashboard 재요청: `06bc097` 이후 scanner-relevant product/dependency/artifact tree가 불변이므로 기존 exact preview evidence를 승계한다.
