## Requirements and non-goals

### 요구사항

- Branch `codex/release-1.1.3-scorecard-refactor`는 exact `origin/main` `e49b5028ad68c55f39eef08405ae78d2971b15ea`에서 시작하며 R-003 후속 조사만 첫 commit으로 보존한다.
- Settings의 두 `SliderComponent`는 유지하고 stable internal class만 추가한다. Preview raw range는 `SliderComponent`로 바꾸며 `setLimits(16,40,1)`, `setInstant(true)`, value/focus/save/reset/number-input 흐름을 보존한다.
- `styles.css`는 slider/reset의 기존 강제 visual styling과 declaration-level `!important` 및 browser-specific range pseudo selector를 0으로 만든다. 세 stable slider class만 current theme의 semantic tokens로 core `--slider-*` contrast/focus fallback을 소유하고, shape·geometry·interaction은 Obsidian native component에 맡긴다.
- Scoped fallback은 `80% --text-normal + 20% --background-primary` contrast token과 theme-derived surface/ink만 사용할 수 있다. 전역 token override, 고정 색, inline important, Shadow DOM, custom slider, selector 반복, CSS layer, scanner 우회는 금지한다.
- `buildSectionInlineVars()`의 dev-only `process.env`/`console.assert` block은 실제 renderer output acceptance로 옮기고 해당 source tranche의 production bundle byte equality를 증명한다.
- Pretext measurement의 canvas/span 생성은 captured document의 `doc.win.createEl("canvas")`와 `doc.win.createSpan()`으로 교체하고 OffscreenCanvas·fallback·emoji·popout·cache를 보존한다.
- Current Obsidian types가 captured-window helpers를 전역 함수로만 선언하므로 기존 `Window` augmentation에 `createEl/createSpan` 두 type-only member를 추가한다. Runtime cast·polyfill·global document fallback은 사용하지 않는다.
- esbuild에는 `charset: "utf8"`만 추가하고 `platform: "node"`와 dependency graph를 유지한다. 두 clean build의 deterministic hash, valid UTF-8, `<5,150,000 bytes`와 `<5 MiB`, CJK/emoji/math/code/export parity를 요구한다.
- Lint warning 상한은 23에서 19로, Scorecard preflight의 `styles.css !important` 상한은 42에서 0으로 낮추고 bundle hard budget을 추가한다.
- Version tuple은 package/lock/manifest `1.1.3`, `versions.json["1.1.3"] = "1.7.2"`로 맞추고 clean committed `main.js`와 bilingual notes를 포함한다.

### 비범위

- 공개 TypeScript API, `AchmageSettings`, 저장 데이터, parser, Pretext/overflow 알고리즘, navigation grammar, HTML export contract 변경
- Declarative settings dual implementation, Direct Filesystem/PostCSS 제거, browser-platform build, source-map stub
- Clipboard, Dynamic Code Execution, first-party overflow `eval`, capability 은폐 또는 scanner gaming
- Dependency 교체·lock graph 변경, MathJax/KaTeX/Highlight 언어/font/background/Marp 제거·외부화
- Settings migration, Remotion, loading/first-preview 성능 최적화 또는 성능 개선 주장
- UI sentence-case warning을 줄이기 위한 브랜드명·기존 문구 변경
- 기존 tag/release/asset 수정, 자동 공개, `1.1.3` tag/asset overwrite

## Documentation and release impact

- **README/사용자 문서:** 제품 grammar/API는 바뀌지 않아 README 기능 설명은 원칙적으로 유지한다. 필요한 경우 native theme ownership과 capability 잔여를 정확히 보강한다.
- **Manifest/package/versions:** `1.1.3`/`1.7.2` tuple로 append-only 전진하고 기존 mappings를 보존한다. Dependency graph는 변경하지 않는다.
- **`main.js` 재생성:** UTF-8 production artifact를 두 번 clean build해 같은 hash/size를 확인하고 committed diff를 검토한다.
- **릴리스·마이그레이션:** Runtime/data migration은 없다. 기존 Node 24/draft-only workflow를 수정하지 않고 세 asset만 attestation과 함께 draft로 만들며 owner 검토 후 수동 공개한다.
