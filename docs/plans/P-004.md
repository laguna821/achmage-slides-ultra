# P-004 — Achmage Slides Ultra 1.1.2 forward-fix 릴리스

## Outcome

- **목표 결과:** 승인·검증된 1.1.0/1.1.1 제품 UX를 그대로 유지하면서 `gh release create`의 repository context 누락만 고쳐, exact new `main` SHA의 annotated `1.1.2` tag에서 attested three-asset non-prerelease draft를 만든다.
- **사용자 가치:** 사용자가 직접 통과시킨 reading-order navigation과 section jump를 되돌리지 않고 공개 가능한 설치 package까지 안전하게 연결한다.
- **완료 정의:** E-004에서 AC-401~AC-408을 각각 정확히 한 번 PASS로 종결하고 P-004/E-004를 complete로 전환한다. PR을 merge commit으로 병합한 뒤 exact `main` Governance/quality green을 확인하고 annotated `1.1.2` tag를 push한다. Actual tag workflow가 source ref/digest, exact three assets/hash, attestation과 non-prerelease draft를 검증하기 전에는 공개하지 않는다.

## Requirements and non-goals

### 요구사항

- `gh release create "$RELEASE_VERSION"`에 explicit `--repo "$GITHUB_REPOSITORY"`를 추가한다.
- `--verify-tag`, `--draft`, explicit title/notes-file와 exact `main.js manifest.json styles.css` arguments를 유지한다.
- Release job에 checkout, `git init`, tag fetch, source execution 또는 manual/dispatch recovery path를 추가하지 않는다.
- Annotated tag object/name/direct commit/peeled SHA, exact main, same-SHA Governance/quality, asset hashes, source ref/digest attestation과 pre/post-write guards를 변경하지 않는다.
- Package/lock/manifest를 `1.1.2`로, `versions.json["1.1.2"]`를 `1.7.2`로 맞추고 기존 entries를 보존한다.
- `docs/release/1.1.2.md`에 한·영 제품 notes와 1.1.0/1.1.1 draft-before-publication failure를 정확히 설명한다.
- `src/**`, `styles.css`, navigation/Pretext/parser/settings/dependency graph는 바꾸지 않는다. Clean `main.js`는 1.1.1 candidate와 byte-identical이어야 한다.
- Exact candidate Dashboard preview는 Risks 0, errors/fails 0, warnings ≤48 locations, categories ≤5를 통과해야 한다.

### 비범위

- Navigation UX revert 또는 추가 제품 변경
- `1.1.0`/`1.1.1` tag 삭제·이동·재생성, release/asset 수동 복구, attestation 삭제
- `--verify-tag`, exact-main, attestation, draft-only 또는 post-write verification 완화
- GitHub CLI/action major upgrade, REST release reimplementation
- Scorecard warning 추가 정리, 성능 최적화, Remotion, native 1920 harness 부채
- Draft 자동 공개. Workflow가 성공해도 owner의 asset/notes/attestation 검토 전에는 draft로 둔다.

## Documentation and release impact

- **README/사용자 문서:** 1.1.0에서 이미 검증된 navigation/help 내용은 변경하지 않는다. Release notes만 1.1.2로 추가한다.
- **Manifest/package/versions:** `1.1.2`/`1.7.2` tuple로 전진하고 1.1.0/1.1.1 mappings는 append-only로 보존한다.
- **`main.js` 재생성:** Clean production build를 실행하고 committed artifact와 기존 candidate의 byte/SHA equality를 기록한다. Diff가 있으면 release를 중지한다.
- **릴리스·마이그레이션:** Runtime/data migration은 없다. 1.1.2 draft에는 `main.js`, `manifest.json`, `styles.css`만 첨부하고 attestation/hash/notes 검토 후 별도 owner 지시 없이는 공개하지 않는다.
