# P-003 — Achmage Slides Ultra 1.1.1 forward-fix 릴리스

## Outcome

- **목표 결과:** 정상인 1.1.0 제품 UX를 그대로 유지하면서 tag checkout의 annotation false negative만 고치고, immutable `1.1.0` tag를 건드리지 않은 채 exact new `main` SHA에서 `1.1.1` annotated tag·attested three-asset draft를 만든다.
- **사용자 가치:** 이미 승인한 section/slide navigation을 되돌리지 않고 Community release를 안전하게 완료하며, source/tag/asset provenance를 약화하지 않는다.
- **완료 정의:** E-003에서 AC-301~AC-308이 정확히 한 번씩 PASS하고 P-003/E-003이 complete가 된다. 병합 후 exact main의 successful Governance를 확인하고 annotated `1.1.1` tag를 push한다. Actual tag workflow가 tag OIDC ref/SHA, 세 asset hash, attestation과 non-prerelease draft를 모두 검증하기 전에는 공개하지 않는다.

## Requirements and non-goals

### 요구사항

- `1.1.0` remote tag object `52a299c6…8108`과 peeled commit `a921c6bd…10af`를 삭제·이동·재생성하지 않는다.
- release tag 이름을 unprefixed `x.y.z`로 검사한 뒤 remote tag를 `refs/release-tags/<version>`에만 fetch한다.
- fetched object type `tag`, direct target type `commit`, local tag-object SHA와 remote SHA, peeled SHA와 `HEAD`/`GITHUB_SHA`를 모두 일치시킨다.
- invalid, missing, lightweight, indirect/moved, event/HEAD mismatch tag를 release write 전에 fail-closed로 거부한다.
- `workflow_dispatch` 또는 manual asset upload를 추가하지 않고 normal tag push provenance를 사용한다.
- 기존 tagged-main Governance, exact-main-head, version tuple, clean build, three assets, attestation source digest/ref, bilingual notes, draft-only 및 post-write ref/hash 검증을 유지한다.
- package/lock/manifest를 `1.1.1`, `versions.json["1.1.1"]`을 `1.7.2`로 맞추고 `docs/release/1.1.1.md`를 추가한다.
- navigation/Pretext/CSS/settings/runtime dependency source diff는 0이어야 하며 `main.js`는 clean build에서 설명 가능한 version-only 여부를 확인한다.
- exact 1.1.1 candidate의 Dashboard preview가 Risks 0, errors/fails 0이고 warning 총수·category 수가 1.0.3보다 비악화여야 한다.

### 비범위

- Open Slide Preview navigation, parser, Pretext, overflow, settings schema, CSS, dependency graph 또는 성능 변경
- `1.1.0` tag/asset overwrite, force-push, tag 삭제·재생성
- attestation source-ref/source-digest, same-SHA main 또는 draft-only guard 완화
- checkout action major upgrade; scoped fetch만으로 root cause를 수정한다.
- Remotion, native 1920 harness 부채, CSS specificity 또는 성능 후보 재개
- draft 자동 공개; 사람 검토와 별도 공개 결정 전에는 draft로 남긴다.

## Documentation and release impact

- **README/사용자 문서:** 1.1.0에서 이미 검증된 내용은 바꾸지 않는다.
- **manifest/package/versions:** `1.1.1`/`1.7.2` tuple로 전진하고 `1.1.0` mapping은 보존한다.
- **`main.js` 재생성:** clean production build를 실행해 committed artifact equality와 hash를 기록한다. 예상 밖 diff가 있으면 릴리스를 중지한다.
- **릴리스·마이그레이션:** migration 없음. `1.1.0`은 tag만 남고 release는 만들지 않는다. `1.1.1` draft에 `main.js`, `manifest.json`, `styles.css`만 첨부하며, attestation·hash·notes 검토 전 공개하지 않는다.
