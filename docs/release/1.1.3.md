# Achmage Slides Ultra 1.1.3

## English

### Scorecard-focused maintenance

- The Preview typography control now uses Obsidian's native `SliderComponent`, matching the two existing Settings sliders while preserving the same 16–40 range, instant updates, number entry, Reset, persistence, and reopen behavior.
- Removed all 42 declaration-level `!important` rules and browser-specific range selectors from the plugin stylesheet. The three sliders use a narrowly scoped, theme-derived contrast fallback while retaining Obsidian's native geometry and interaction.
- The frozen Default, Minimal, AnuPpuccin, and Obsidianite matrix verified every slider at greater than 3:1 for track, thumb, and focus contrast. Keyboard, pointer, and native Windows drag behavior remained functional.
- Moved development-only renderer assertions into acceptance tests and switched two Pretext measurement elements to document-scoped Obsidian helpers without changing emitted renderer output, cache behavior, pop-out ownership, or overflow results.

### Distribution artifact

- The production bundle is emitted as deterministic UTF-8. This reduces distribution size by about 173 KB (3.3%) compared with 1.1.2 while keeping the same node platform and dependency graph.
- This is a representation-size change, not evidence of faster plugin loading. Version 1.1.3 makes no loading-speed or first-Preview performance claim.
- Production and full dependency audits report zero vulnerabilities. Local type-aware lint remains at zero errors and 19 reviewed warnings.

### Compatibility and known limitations

- Public TypeScript API, settings schema, saved state, parser, Pretext/overflow algorithm, navigation, and HTML export behavior are unchanged. Export remains officially supported on Obsidian Desktop.
- Declarative settings migration, Direct Filesystem provenance, clipboard and dynamic-code capabilities, first-party overflow `eval`, math engines, syntax languages, fonts, backgrounds, and Marp remain unchanged.
- The bundle remains above the optional 4.9 MB target. Reduced bytes are not presented as a performance improvement or as a guarantee that every public size warning disappears.
- The exact candidate is released only if the Obsidian Developer Dashboard reports `Satisfactory 3/4`, Risks 0, and no errors or failures.

## 한국어

### Scorecard 중심 유지보수

- Preview의 글자 크기 조절을 Obsidian 기본 `SliderComponent`로 통일했습니다. 기존 Settings 슬라이더 두 개와 같은 구조를 사용하면서 16–40 범위, 즉시 반영, 숫자 입력, Reset, 저장과 재개방 동작은 그대로 유지합니다.
- 플러그인 stylesheet의 declaration-level `!important` 42건과 브라우저별 range selector를 모두 제거했습니다. 세 슬라이더에만 현재 테마 색을 이용한 제한적 대비 fallback을 적용하고 Obsidian 기본 geometry와 interaction은 유지합니다.
- 고정된 Default, Minimal, AnuPpuccin, Obsidianite matrix에서 세 slider의 track, thumb, focus 대비가 모두 3:1을 넘는지 확인했습니다. Keyboard, pointer, 실제 Windows drag도 정상 동작했습니다.
- 개발 전용 renderer assertion은 acceptance test로 옮기고 Pretext measurement의 DOM 생성 두 곳은 document-scoped Obsidian helper로 교체했습니다. Renderer output, cache, pop-out document ownership, overflow 결과는 바뀌지 않았습니다.

### 배포 산출물

- Production bundle을 결정론적 UTF-8로 출력합니다. Node platform과 dependency graph를 유지하면서 1.1.2보다 배포 크기가 약 173 KB(3.3%) 줄었습니다.
- 이는 표현 방식에 따른 배포 크기 감소이지 plugin loading 속도 향상의 증거가 아닙니다. 1.1.3은 loading 또는 first Preview 성능 개선을 주장하지 않습니다.
- Production/full dependency audit는 모두 취약점 0건이며, type-aware lint는 error 0건과 검토된 warning 19건입니다.

### 호환성과 알려진 제약

- 공개 TypeScript API, 설정 schema, 저장 상태, parser, Pretext/overflow 알고리즘, navigation, HTML export 동작은 바뀌지 않았습니다. Export는 계속 Obsidian Desktop만 정식 지원합니다.
- Declarative settings 전환, Direct Filesystem provenance, clipboard와 dynamic-code capability, overflow 검증용 first-party `eval`, 수식 엔진, syntax language, font, background, Marp는 이번 patch에서 변경하지 않았습니다.
- Bundle은 선택적 4.9 MB 목표보다 큽니다. Byte 감소를 성능 향상으로 표현하지 않으며 공개 size warning이 반드시 사라진다고 보장하지 않습니다.
- Exact candidate가 Obsidian Developer Dashboard에서 `Satisfactory 3/4`, Risks 0, error/fail 0을 충족할 때만 릴리스합니다.
