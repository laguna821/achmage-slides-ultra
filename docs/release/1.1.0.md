# Achmage Slides Ultra 1.1.0

## English

### Navigation that follows the reading order

- **Next** now moves through every generated frame before entering the next section. `Right`, `Down`, `PageDown`, `Space`, `N`, and a right-side stage click use the same route; the reverse controls retrace it exactly.
- Dedicated **⇤ Section** and **Section ⇥** controls still jump directly between section starts. `Home` and `End` go to the real first and last frame of the deck.
- The persistent bar shows both levels (`Section 2/7 · Slide 1/3`) and changes its arrow to show whether the next step continues downward or enters the next section.
- Frame dots are semantic buttons with larger targets and roving keyboard focus. Only the current frame remains in the accessibility tree, Preview iframes have useful titles, focus is restored after navigation, and reduced-motion preferences disable navigation animation.
- Live Preview and exported desktop HTML now use the same controls, keyboard grammar, and help.

### Scorecard and release hygiene

- Removed runtime-erased assertions, a stale helper, Promise-handler findings, and an iterator edge case without changing the parser, Pretext measurement, frame topology, or overflow algorithm.
- Patched the transitive production dependency graph and upgraded the build tool to `esbuild 0.28.1`; production and full `npm audit` both report zero vulnerabilities for this candidate.
- Added type-aware Obsidian lint, a local Scorecard preflight, a substantive contribution guide, Node 24 CI, full-SHA action pins, exact-SHA governance gates, asset hashes, provenance attestations, and a draft-only release workflow.

### Compatibility and known limitations

- Settings schema, saved state, public TypeScript API, parser behavior, and export capability are unchanged. Export remains officially supported on Obsidian Desktop.
- The measured performance candidate did not pass the joint load/first-preview gate, so 1.1.0 contains no performance product change and makes no loading-speed claim.
- The community-theme matrix rejected the proposed `!important` removal, so all 42 existing declarations remain. Local lint is fixed at 0 errors and 23 reviewed warnings, mostly brand/theme casing, intentional development assertions, declarative-settings migration, and vendored compatibility findings.
- The bundle remains above the optional 4.9 MB target. Intentional network/image embedding, runtime base64, clipboard write-only, local `FileSystemAdapter`, first-party overflow `eval`, math engines, and syntax languages remain available and documented.
- The historical `acceptance:native-1920-v5` entry has no recoverable source harness; it was not silently recreated or used as a release gate. The maintained overflow and navigation suites are the release gates for 1.1.0.

## 한국어

### 읽기 순서를 그대로 따르는 내비게이션

- 이제 **Next**는 현재 섹션에서 자동 생성된 모든 프레임을 지난 다음 다음 섹션으로 넘어갑니다. `Right`, `Down`, `PageDown`, `Space`, `N`, 화면 오른쪽 클릭이 같은 경로를 사용하며 반대 조작은 그 경로를 정확히 거슬러 갑니다.
- 별도의 **⇤ Section**, **Section ⇥** 버튼은 계속 섹션 시작점 사이를 바로 이동합니다. `Home`과 `End`는 덱의 실제 첫 프레임과 마지막 프레임으로 이동합니다.
- 항상 보이는 하단 바는 `Section 2/7 · Slide 1/3`처럼 섹션과 프레임 위치를 함께 표시하고, 다음 단계가 같은 섹션 아래인지 다음 섹션 오른쪽인지 화살표로 알려 줍니다.
- 프레임 점은 더 큰 클릭 영역과 roving keyboard focus를 갖는 실제 버튼입니다. 현재 프레임만 접근성 트리에 남고, Preview iframe 제목·내비게이션 후 focus 복구·reduced-motion 처리를 추가했습니다.
- Live Preview와 데스크톱 내보내기 HTML이 동일한 버튼·키보드 문법·도움말을 사용합니다.

### Scorecard 및 릴리스 정리

- parser, Pretext measurement, frame topology, overflow 알고리즘은 그대로 유지하면서 runtime에서 사라지는 assertion, 오래된 helper, Promise handler finding과 iterator edge case를 정리했습니다.
- production transitive dependency를 패치하고 build tool을 `esbuild 0.28.1`로 올렸습니다. 이 후보에서 production/full `npm audit`는 모두 취약점 0건입니다.
- type-aware Obsidian lint, 로컬 Scorecard preflight, 실질적인 기여 가이드, Node 24 CI, action full-SHA pin, exact-SHA governance gate, asset hash, provenance attestation, draft-only release workflow를 추가했습니다.

### 호환성과 알려진 제약

- 설정 schema, 저장 상태, 공개 TypeScript API, parser 동작, export capability는 바뀌지 않았습니다. Export는 계속 Obsidian Desktop만 정식 지원합니다.
- 측정한 성능 후보는 plugin load와 first Preview 공동 gate를 통과하지 못했습니다. 따라서 1.1.0에는 성능 제품 변경이 없으며 로딩 속도 향상을 주장하지 않습니다.
- community theme matrix에서 `!important` 제거 후보가 탈락해 기존 42건을 그대로 유지했습니다. 로컬 lint는 error 0, 검토된 warning 23건으로 고정했으며 대부분 브랜드·테마 표기, 의도된 개발 assertion, declarative settings 전환, vendored compatibility 범주입니다.
- bundle은 선택적 4.9 MB 목표보다 큽니다. 의도된 network/image embedding, runtime base64, clipboard write-only, local `FileSystemAdapter`, overflow 검증용 first-party `eval`, 수식 엔진과 syntax language는 유지하고 문서에 공개했습니다.
- 과거 `acceptance:native-1920-v5` entry는 원본 harness source가 없어 임의로 복구하거나 release gate로 쓰지 않았습니다. 1.1.0은 유지되는 overflow·navigation suite를 release gate로 사용합니다.
