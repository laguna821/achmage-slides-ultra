# Achmage Slides Ultra 1.1.4

## English

### Navigation polish

- Fixed a fullscreen focus regression: after selecting the fullscreen control, slide navigation now accepts the first arrow key immediately without requiring an extra click.
- Removed the browser-generated orange perimeter from the noninteractive presentation stage while retaining visible keyboard focus rings on actual buttons and slide dots.
- Added a visible **Home** control before Previous. It returns directly to the first slide in the deck and then restores the presentation keyboard context.
- Replaced the ambiguous `Full` / `Exit` text with action-oriented **Fullscreen on** / **Fullscreen off** labels. Home and fullscreen use a consistent ASU teal treatment in the bottom bar.

### Compatibility and known limitations

- Reading-order navigation, section jumps, keyboard Home/End, parser behavior, Pretext/overflow, settings schema, saved state, and HTML export behavior remain compatible with 1.1.3. Live Preview and exported desktop HTML use the same updated controls.
- This patch does not change loading or first-Preview performance and makes no performance improvement claim.
- Declarative settings search, Direct Filesystem provenance, clipboard writes, dynamic code execution, and the existing first-party overflow evaluation remain unchanged and continue to be disclosed.

## 한국어

### 내비게이션 다듬기

- Fullscreen control을 선택한 뒤 추가로 화면을 클릭해야 방향키가 동작하던 focus 회귀를 수정했습니다. 이제 fullscreen에 들어간 직후 첫 방향키부터 slide navigation이 동작합니다.
- 실제 button과 slide dot의 keyboard focus ring은 유지하면서, 비대화형 presentation stage에 브라우저가 표시하던 주황색 외곽선을 제거했습니다.
- Previous 앞에 visible **Home** control을 추가했습니다. 긴 deck의 어느 위치에서도 첫 slide로 바로 돌아가고 presentation keyboard context를 복구합니다.
- 모호했던 `Full` / `Exit` 문구를 현재 action을 설명하는 **Fullscreen on** / **Fullscreen off**로 바꿨습니다. Home과 fullscreen은 하단 바에서 일관된 ASU teal 강조를 사용합니다.

### 호환성과 알려진 제약

- Reading-order navigation, section jump, keyboard Home/End, parser, Pretext/overflow, 설정 schema, 저장 상태와 HTML export 동작은 1.1.3과 호환됩니다. Live Preview와 desktop exported HTML은 같은 새 control을 사용합니다.
- 이 patch는 loading 또는 first Preview 성능을 변경하지 않으며 성능 개선을 주장하지 않습니다.
- Declarative settings search, Direct Filesystem provenance, clipboard write, dynamic code execution과 기존 first-party overflow evaluation은 변경하지 않고 계속 공개합니다.
